# Exam and admin preview update

Implemented locally on 2026-10-05. This change has not been deployed.

The admin test area now has دخول الاختبار, a full-screen participant exam view, خروج من الاختبار, and a separate resume action. Exiting preserves the attempt, selected question, answers and reading progress. Real participants use the same compact full-screen exam, without the admin controls. Test attempts retain their isolated server and IndexedDB namespaces.

The book displays a continuous sequence of pages. Only canvases near the viewport render, and inactive renders cancel on unmount. Page arrows, current PDF page, page count and zoom are in the header; the old separate navigation row and repeated source-page labels are removed. Scroll position updates the header without snapping the reader back to a page boundary. The existing file checksum and page-count verification remain in place.

Hints retain the existing eligibility rule of reading beyond the source page. Clicking a hint shows only the source page and its preceding page. Page 1 has no preceding page. The reader has a return-to-full-book action, and changing questions clears the restriction. Keyboard focus remains inside the mobile reader when its hint controls disappear; Escape returns to the question.

Per the requested policy change, the server returns correctness and answer explanations after locking an answer, including existing campaigns with the legacy formal setting. Unchecked questions still exclude keys and explanations. A wrong selection and the correct option have separate colors, icons and labels. Answers remain immutable after checking; offline checks show pending confirmation until the server returns feedback. The admin settings, participant introduction, FAQ and displayed terms describe the new policy.

The question panel has no internal scrollbar. Compact controls, answer rows and question navigation keep the tested content accessible within smaller viewports. At 320px the question map becomes a labeled dropdown; answer status icons retain their accessible text. Arbitrarily long authored questions may still require page scrolling; content is not truncated or clipped.
